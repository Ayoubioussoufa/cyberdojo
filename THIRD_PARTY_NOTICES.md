# Third-party notices

CyberDojo's dojo modules were inspired by [pwn.college](https://pwn.college/), the open cybersecurity
course from Arizona State University. It is well worth doing in full, because it runs real programs and
real exploits, which this site deliberately doesn't.

All exercise text and code here was written for CyberDojo. No challenge from pwn.college was copied.

- **Pipes and streams** and **Permissions** follow the sequence of ideas in
  [Linux Luminarium](https://github.com/pwncollege/linux-luminarium), which is distributed under the
  BSD 2-Clause licence reproduced below.
- **Bytes and encodings, Questioning a database, Talking to the web, XOR and its traps, Access control**
  and **Privilege audit** cover topics that pwn.college also covers (Playing With Programs, Intro to
  Cybersecurity). Those repositories state no licence, so only the general topics were used: no
  challenge, wording or solution was taken from them.
