# Modules

Generated by `pnpm audit:coverage`. One folder per domain, and in each one the modules run from foundation to advanced. Every module has the same seven parts: Concept, Threat model, Tools, Defence, Pitfalls, Exercise, Further reading.

- [01 Networking and protocols](01-networking/README.md): 14 modules. What really crosses the wire, and how to see it, shape it and abuse it.
- [02 Operating systems and privilege escalation](02-operating-systems/README.md): 10 modules. Linux and Windows from the kernel up, how an account climbs, and Active Directory.
- [03 Cryptography](03-cryptography/README.md): 12 modules. The maths, the constructions, and the many ways that sound primitives get misused.
- [04 Web security](04-web/README.md): 14 modules. The browser and server model, every injection class, and the fixes that hold.
- [05 Application and binary security](05-binary/README.md): 10 modules. How programs fail at the level of memory, how mitigations answer, and how bugs are found.
- [06 Malware, evasion and EDR](06-malware-edr/README.md): 7 modules. What malware does, how it hides, and how endpoint detection actually sees it.
- [07 Network security and infrastructure](07-network-security/README.md): 7 modules. Firewalls, sensors, VPNs and architectures that assume the attacker is already in.
- [08 Blue team and defensive operations](08-blue-team/README.md): 9 modules. Detection platforms, threat hunting, and forensics that holds up.
- [09 Threat intelligence and frameworks](09-threat-intel/README.md): 5 modules. Shared models of the adversary, threat modelling methods, and open-source reconnaissance.
- [10 Cloud and container security](10-cloud/README.md): 7 modules. AWS, Azure and GCP attack paths, container isolation, Kubernetes and infrastructure as code.
- [11 Identity and access](11-identity/README.md): 5 modules. Formal models, authentication mechanics, and federation attacks.
- [12 Governance, risk, compliance, ethics and law](12-grc/README.md): 7 modules. Quantified risk, regulation, disclosure, and where the legal lines sit.
- [13 Software supply chain and secure SDLC](13-supply-chain/README.md): 3 modules. Attacks on what you build with, and the maturity models that answer them.
- [14 AI and machine-learning security](14-ai-security/README.md): 1 modules. Adversarial machine learning beyond the prompt.
- [15 Wireless, mobile, hardware, OT and physical](15-wireless-mobile-hardware-ot/README.md): 9 modules. Security below and beside the operating system, where bugs can't always be patched.
- [16 Human factors, privacy and research foundations](16-human-privacy-research/README.md): 7 modules. People, privacy, and how a Master's student reads and does security research.
