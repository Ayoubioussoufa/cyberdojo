## Modules

### Foundation

- [Browser defences and CSP](01-browser-defences-and-csp.md): The headers that turn a browser into your ally. Content Security Policy, HSTS, cookie settings, isolation headers and Trusted Types, and how to deploy them without breaking a site.

### Intermediate

- [SQL injection in depth](02-sql-injection-in-depth.md): Why injection still appears, its classes as seen in code review and in logs, why ORMs and WAFs aren't complete answers, and how to build database access that can't be injected.
- [Injection beyond SQL](03-injection-beyond-sql.md): One root cause in many languages. OS commands, code evaluation, NoSQL, LDAP, XPath, templates and XML, with the safe API for each and how to spot the risky ones in review.
- [XSS in depth](04-xss-in-depth.md): Why output encoding depends on context, how DOM XSS differs, what modern frameworks do and don't protect, and how to remove the class with safe sinks and Trusted Types.
- [Client-side web security](05-client-side-attacks.md): Beyond XSS. Clickjacking, open redirects, postMessage, WebSockets and prototype pollution, each with the browser behaviour behind it and the simple check that closes it.
- [Authentication and JWT security](06-authentication-and-jwt-attacks.md): Building login that holds up. Reset flows, account enumeration, session handling, and the JWT verification mistakes that keep turning into authentication bypasses.
- [File handling security](08-files-traversal-and-uploads.md): Paths and uploads look simple and go wrong often. Why path checks must happen after resolution, how to store untrusted files safely, and how web shells get detected.
- [API security, GraphQL and gRPC](12-api-security-graphql-grpc.md): APIs have replaced pages as the main attack surface. Object-level authorisation, GraphQL's cost and field risks, gRPC's trust assumptions, and how to inventory what you expose.
- [The web testing workflow](13-testing-workflow-burp.md): How an authorised assessment runs from scope to report. Using Burp and ZAP properly, content discovery, automated scanners and their limits, and writing findings that get fixed.
- [The rest of the OWASP Top 10](14-owasp-2025-gaps.md): Four categories the course only named. Security misconfiguration, data integrity failures, logging that doesn't alert, and code that fails unsafely when something goes wrong.

### Advanced

- [SSRF in depth](07-ssrf-in-depth.md): When your server makes requests for an attacker. Why filters fail, why cloud metadata raised the stakes, and the network-level design that makes the class far less dangerous.
- [Insecure deserialization](09-deserialization.md): Some data formats can rebuild live objects, and that's what makes them dangerous. Why native serialization leads to code execution, what Log4Shell shared with it, and how to design it out.
- [HTTP desync and cache security](10-desync-and-cache-attacks.md): When two servers disagree about one request. Why request smuggling exists, how web caches can be poisoned or tricked, and the architecture choices that close both.
- [Business logic and race conditions](11-logic-flaws-and-races.md): Flaws no scanner can see, because the code works as written. How to find broken assumptions, why concurrency turns one check into a gap, and how transactions close it.
