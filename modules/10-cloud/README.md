## Modules

### Intermediate

- [AWS privilege paths and hardening](01-aws-attack-paths.md): How identity decides everything in AWS. Why a few IAM permissions amount to admin, how metadata and storage exposures happen, and the guardrails and detections that stop them.
- [Azure security](02-azure-security.md): Azure has two permission systems, and mixing them up causes real exposure. Tenants, subscriptions, RBAC, managed identities, storage tokens, and the logs that matter.
- [Google Cloud and multi-cloud](03-gcp-and-multi-cloud.md): Google Cloud's resource hierarchy and IAM, service account risk, default logging gaps, and a working translation table for staying secure across three providers.
- [Serverless and secrets management](04-serverless-and-secrets.md): With no servers to patch, what's left to secure? Function permissions, event input and logging, plus how to store, rotate and retire secrets in a modern platform.
- [Infrastructure as code and policy as code](07-iac-and-policy-as-code.md): When infrastructure is code, a pull request can open a database to the world. Protecting state, detecting drift, reviewing plans, and enforcing rules automatically with OPA.

### Advanced

- [Container isolation and runtime security](05-container-escape-and-runtime.md): What keeps a container in its box, the settings that quietly remove those walls, and how sandboxed runtimes and runtime detection reduce the damage when something goes wrong.
- [Kubernetes security in depth](06-kubernetes-attack-paths.md): The control plane, RBAC, service accounts, secrets and network policy. How a cluster's defaults create risk, and the layered controls that keep one pod's problem from spreading.
