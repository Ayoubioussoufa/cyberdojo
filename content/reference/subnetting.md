## The method

Example: `192.168.10.140/26`

| Step | Work |
|---|---|
| 1. Host bits | 32 − 26 = 6 |
| 2. Addresses | 2⁶ = 64 |
| 3. Block size | 64, so networks start at 0, 64, 128, 192 |
| 4. Network | 140 falls in 128, so `192.168.10.128` |
| 5. Broadcast | Next block minus 1: `192.168.10.191` |
| 6. Usable | `.129` to `.190`, which is 62 hosts |

**Usable hosts = 2^(host bits) − 2.** One address is the network, and one is the broadcast.
