## Step 4: Evaluate it

@goal Write a harness that runs every item and reports precision, recall, cost per item and time per item. Run it several times, and record the model's name and version with each result.
@search precision recall explained | evaluating llm classification python

@help promptfoo recall

**Your task:** write a harness that runs every item, and reports precision, recall, cost per item and time per item. You could use promptfoo from P15, or plain Python.

@reveal Which should I use?
promptfoo is quickest for pass or fail checks. For precision and recall across 100 items, a short Python script or a test with `pytest` is often simpler: loop over your dataset, count TP, FP and FN, and print the table.
@endreveal

@help pytest solo

Run it several times, because models vary. Record the model's name and version with each result.

## Step 5: Learn from its failures

@goal Sort every failure into named categories. Pick the biggest one, change something, and measure again. Keep a changelog with before-and-after numbers.
@search error analysis llm evaluation | failure taxonomy machine learning

Sort every failure into named categories, which gives you a **failure taxonomy**, as in [lesson 77](/courses/0077-evaluating-ai-and-your-capstone/). Pick the biggest one, change something, and rerun the **whole** set. Keep a changelog of what really moved the numbers, and what didn't.
